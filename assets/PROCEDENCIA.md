# Fotos para el bloque de dotación

Generadas con la herramienta integrada de ImageGen. Se usaron las mismas imágenes para compra y venta; no contienen precios, marcas ni señales de propiedad. Exportación WebP a igual resolución, calidad 88, para reducir la transferencia en celulares.

## assets/lentes.webp

Prompt final:

Use case: product-mockup. Asset type: photograph used as an identical stimulus for two randomly assigned groups in a university psychology classroom experiment. Create one realistic studio product photograph of a single exceptionally stylish pair of unbranded black acetate sunglasses, slightly angular wayfarer shape, smoky dark lenses, open temples, three-quarter front view. Warm light gray seamless studio background, very soft natural grounding shadow, refined softbox lighting, crisp and tactile materials, restrained premium catalog aesthetic. Object fully visible centered with generous margins, square composition. No people, no hands, no text, no visible prices, no logos, no brand marks, no watermark, no extra objects, no packaging. Attractive desirable but plausible everyday consumer object. Do not depict any ownership cues.
